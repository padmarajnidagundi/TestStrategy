# TestStrategy

A lightweight project for the public AI testing strategy dashboard and supporting project assets.

## Live Demo

- https://padmarajnidagundi.github.io/TestStrategy/

## Overview

This repository now focuses on the dashboard and the project landing page. Older long-form test strategy content has been removed to keep the public site concise and easier to navigate.

## Included

- Interactive dashboard
- Supporting project assets
- Simple documentation for the site

## Files

- `index.html` — public GitHub Pages landing page
- `README.md` — repository overview
- `Lean_Canvas_Test_Strategy_Dashboard.jpg` — project image asset

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.
