# TestStrategy

A public-facing project for an AI testing strategy dashboard and supporting project assets.

## Live Demo

- https://padmarajnidagundi.github.io/TestStrategy/

## Overview

This repository hosts a streamlined landing page and supporting materials for a testing strategy dashboard. The goal is to present the project clearly and professionally in a public GitHub Pages experience without carrying unnecessary legacy content.

## Included

- Public GitHub Pages landing page
- Dashboard-focused project overview
- Supporting visual asset for the initiative
- Simple project documentation

## Project Files

- `index.html` — public landing page for the project
- `README.md` — project overview and usage information
- `Lean_Canvas_Test_Strategy_Dashboard.jpg` — dashboard image asset
- `PD_Nidagundi_FINAL_A4.pdf` — supporting project document

## Local Preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
